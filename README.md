# 江苏海洋大学校园网自动登录

适配江苏海洋大学 Dr.COM / ePortal 校园网认证，提供 Windows 后台工具和 iPhone Scriptable 脚本。个人项目，非学校官方客户端；需要自己的有效校园网账号。

## 2026-09 更新：缩短开机后的等待

- Windows 自启动改为当前用户登录计划任务，触发延迟设为 0，避免普通启动项较晚运行。
- 校园网服务器暂不可达或尚未取得可认证的校园网地址时，每次失败后等待 5 秒再检查。
- 已在线时每 30 秒检查；认证被拒绝时仍等待 5 分钟，连续失败 3 次后暂停，重新保存配置可恢复。
- 日志增加“后台已启动”时间，方便区分程序启动慢与网络未就绪。
- 不要求电脑插电，也不等待 Windows 判定“可访问互联网”才启动。

0 秒指任务没有人为设置的触发延迟，不代表开机后 0 秒认证完成；实际耗时取决于 Windows、网络和学校认证服务器。已验证计划任务可启动后台并检查在线状态，完整关机后再开机的耗时仍需实际验证。

## Windows 使用

1. 点击 **Code → Download ZIP** 下载，解压到你准备长期保留的文件夹。
2. 保持 `CampusHelper.ps1` 和两个 `.cmd` 文件在同一文件夹，双击 `启动校园网自动登录.cmd`。
3. 填账号、密码并选择运营商（默认中国联通），勾选“登录 Windows 后自动运行”，点击“保存并启用”。
4. 关闭设置窗口后，后台继续工作。请检查界面是否提示“开机启动设置失败”。

任务名称是 `JOU-Campus-AutoLogin`，以当前用户普通权限运行，不保存 Windows 登录密码。任务注册成功后，自动移除旧版同名 Run 启动项。

### 已有用户如何更新

用新版 `CampusHelper.ps1` 替换原文件，然后打开设置窗口，保持原账号，密码可留空，勾选自动运行并点击“保存并启用”。**只替换文件不会自动迁移已有启动项。**

已运行的旧后台进程会继续使用旧代码；保存后下次登录 Windows 即使用新版。若移动程序文件夹，也需要从新位置打开设置并重新保存，以更新启动路径。

双击 `关闭开机自动登录.cmd` 可禁用计划任务并移除旧启动项，已运行的后台仍会持续到退出 Windows。详见 [Windows 使用说明](说明.md)。

## iPhone 使用

1. 安装 Scriptable，在其中新建脚本，粘贴 `JOU校园网自动登录.js` 的全部内容并命名。
2. 连接校园 Wi-Fi，在 Scriptable 内先手动运行一次，填写自己的账号和密码。当前手机脚本固定使用 **中国联通**。
3. 在“快捷指令 → 自动化”里选择加入校园 Wi-Fi 时触发，添加 Scriptable 的运行脚本操作，选择该脚本。系统提供“立即运行”时可选用；具体执行与授权提示依 iOS 设置而定。

修改账号或密码：给脚本传入文本参数 `reset` 并运行一次，重新填写后删除该参数，避免每次清空配置。

手机脚本每次触发只执行一轮，不会像 Windows 程序一样一直在后台检查；保持连接同一 Wi-Fi 但认证过期时，可以手动运行快捷指令。

## 凭据和文件位置

- Windows 凭据使用当前用户 DPAPI 加密，配置与日志在 `%LOCALAPPDATA%\JOUCampusAutoLogin\`。
- iPhone 凭据由 Scriptable 的 Keychain 保存，不写入脚本。
- 仓库不包含用户账号密码、运行配置或日志；程序不会主动注销校园网。
- 认证接口使用 HTTP，网页参数编码不等于 HTTPS。仅用于自己有权使用的校园网账号。
- 学校认证页面或接口发生变化时，可能需要重新适配。
