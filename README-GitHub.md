# 江苏海洋大学校园网自动登录

适用于江苏海洋大学当前 Dr.COM / ePortal 校园网认证页面的个人自动登录工具，默认运营商为**中国联通**。

## Windows

- `CampusHelper.ps1`：主程序。首次运行时弹出账号、密码设置窗口；密码经 Windows 当前用户加密保存。
- `启动校园网自动登录.cmd`：双击打开设置窗口。
- `关闭开机自动登录.cmd`：关闭 Windows 登录后的后台启动。

设置完成后，主程序会在后台检测认证状态；掉线时自动认证，不会主动断开校园网。

## iPhone

- `JOU校园网自动登录.js`：导入免费的 Scriptable App 后运行。账号和密码仅保存在该 iPhone 的系统钥匙串。

在 iPhone「快捷指令」的 Wi-Fi 自动化中添加“运行 Scriptable 脚本”，选择这个脚本即可。首次运行时输入账号和密码；需要改密码时，向脚本传入参数 `reset`，再运行一次。

## 安全与使用说明

- 本仓库**不包含**任何真实账号、密码、电脑配置或认证日志。
- 只会访问江苏海洋大学校内认证地址 `210.28.39.250`。
- 这是为个人有权使用的校园网账号提供的自动化工具。学校若改版认证页面，脚本可能需要更新。
